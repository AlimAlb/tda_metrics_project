# tda_metrics

Курсовой проект: сравнение топологических и статистических метрик схожести распределений
(MTD, RTD, improved precision/recall, MMD, Fréchet, JS) на управляемых 2D-экспериментах
и эмбеддингах реальных данных (CLIP).

## Структура

```
├── src/tda_metrics/        # пакет: сэмплеры, метрики, пайплайн экспериментов, CLIP
├── notebooks/
│   └── topology_metrics.ipynb   # основной ноутбук (нарратив + эксперименты)
├── tests/                  # pytest-инварианты (запускать на Colab-VM)
├── results/                # executed-ноутбуки с результатами
└── archive/                # старая RnD-версия ноутбука (референс)
```

## Запуск в Colab

1. Открыть `notebooks/topology_metrics.ipynb` в Colab (GPU-runtime: ripser++
   собирается с CUDA).
2. Первая код-ячейка клонирует этот репозиторий, ставит пакет
   (`pip install -e`) и heavy-зависимости (ripser++, MTopDiv, RTD,
   improved-precision-recall).
3. Дальше — сверху вниз. Время: §1–2 ~5 мин, §3 ~50–70 мин (основная стоимость —
   баркоды RTD/MTD), §5 ~15 мин (эмбеддинги кэшируются).

## Запуск тестов (на Colab-VM)

```
pip install pytest && pytest tests/ -q
```

## Заметки

- MTD/RTD требуют GPU-рантайм; improved PR и статистические метрики работают на CPU.
- Значения MTD при разных `batch_size` несравнимы — обертка всегда считает на полных облаках.
- RTD инвариантен к сдвигам облаков (строится только из внутренних попарных расстояний).
